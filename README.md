# Eesti-keel-A1
Eesti keele A1-taseme interaktiivsed harjutused iseseisvaks õppimiseks. / Interactive A1 Estonian exercises for independent study.
## 16. peatükk „Mis sulle maitseb?“

**Fail** `Mis_sulle_maitseb_A1.html`  
**Tase ja kasutus** A1, iseseisev harjutamine Moodle’i kaudu.

Õppija kordab toidu ja joogi sõnavara ning harjutab sõnakaartidega kolme käändevormi (*nimetav, omastav, osastav*). Ta õpib kasutama lõppe **-ga** ja **-ta** (*kohv piimaga, kohv suhkruta*) ning harjutab tegusõnu *sööma, jooma, tahtma* ja *maitsema*.

Harjutuses on sõnakaardid, lugemisküsimused Imbi pere hommikusöögi ja ostunimekirja kohta, lünkülesanded, kümme kohvikutellimust ning kümme inglise keelest eesti keelde tõlgitavat lauset. Töökäsud on eesti ja inglise keeles.
